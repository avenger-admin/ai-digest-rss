# AI digest RSS (TLDR)

Public GitHub Pages feed for Feeder / other readers.

**Feed URL:** https://avenger-admin.github.io/ai-digest-rss/feed.xml

## Format
Each weekday item: **Do this week** then **Watch**. Full write-up stays in Grok Bot.

## Update
Use `append_item.py` locally, then replace `feed.xml` on `main` (keep ~30 days). Pages serves from `/` on `main`.
