Gemini 4 Carbon is now open to everyone

Two weeks after giving it only to cybersecurity defenders, Google has released Gemini 4 Carbon, its strongest model, to paying developers, businesses and Google AI Ultra subscribers. It’s built for the really hard stuff: long multi-step coding and debugging, deep research and big agent workflows. Google says it ranks #1 on CursorBench 4.0 at less than half the cost per task of the next best outside model.

It costs $2 in and $10 out per million tokens until 30 November, then $4 and $20. Google Antigravity also gets a preview of /swarm, which turns one prompt into a team of agents you can watch working in real time. Google still suggests Gemini 4 Argon for most everyday work.

AI agents prove Signal’s encryption code is secure

Google DeepMind’s new AlphaProof Code mathematically proved key security properties of libsignal, the code behind the Signal protocol that protects chats in Signal, Google Messages and WhatsApp. Humans and AI agreed what to prove, then Carbon-powered agents wrote about 6.5 million lines of Lean proof, each checked by machine, in about four weeks instead of the years this kind of work usually takes.

As a sanity check, they put two old, already-fixed bugs back in, and the system correctly showed those versions were insecure. It covers one-to-one messaging rather than the whole app, and the proofs are public for others to build on.

Claude gets Sheets, Whiteboards and Meetings

At an event in San Francisco, Anthropic launched Claude Sheets and Claude Whiteboards in beta on all paid plans. Sheets builds working spreadsheets from a prompt (tabs, formulas, dropdowns, charts), highlights each edit Claude makes, and exports to Excel or CSV. Claude Data (previously Dashboards) is now generally available too.

There’s also Claude Meetings for Team and Enterprise, which joins video calls and starts on tasks while people are still talking. Together it looks a lot like Anthropic’s own office suite.

From the inbox: the “missing quadrant” in how we think about AI

Arvind Narayanan, Sayash Kapoor and Rishi Bommasani from AI as Normal Technology are starting STABL, a non-profit lab studying how AI actually changes society. Their pitch is a simple 2×2: one camp thinks superintelligence will sweep every obstacle aside, the other treats today’s institutions as fixed and tries to hold AI back.

STABL wants the overlooked corner: take AI seriously and take the bottlenecks seriously, then ask how to fix them. Their example is medicine, where AI might speed up drug discovery but clinical trials still take years, so the real question is how to make testing faster and safer.

Hands-on pick: build a model router for Claude Code

NextWork’s latest weekly release adds a project that builds a Claude Code skill to pick the right model for each task. It uses TypeSafe’s Jev to recommend Haiku or Sonnet, stops vague or risky jobs for a human to check, and then hands approved work to the chosen model.

You’ll need Claude Code plus an OpenRouter or TypeSafe key that can call Jev. The same changelog also adds sharing for private projects and NextWork Proof recording on Windows.

Worth a look at work

Two small things point the same way on cost: Google says to keep Gemini 4 Argon for most coding and save Carbon for the hardest jobs, and today’s NextWork project builds a router that sends routine tasks to Haiku and only escalates when it needs to. Both fit nicely with keeping token spend sensible.
