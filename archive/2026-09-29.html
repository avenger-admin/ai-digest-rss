A short, friendly skim of what’s new in AI — so you can start the day curious, not buried.

Claude Sonnet 5.5 is here — faster, leaner, still sharp

Anthropic’s second Claude 5.5 model keeps the same list price as Sonnet 5, but runs ~30%+ faster and can cost up to ~30% less per task thanks to fewer tokens and steps. On agentic coding benchmarks it leaps ahead (Terminal-Bench 4.0: 70.6% vs Sonnet 5’s 10.3%).

It’s live on the Claude Platform plus AWS Bedrock, GCP, and Azure — so you can try it wherever your stack already talks to Claude.

Anthropic announcement →

GitHub Copilot gets Sonnet 5.5 across the board

Sonnet 5.5 is GA in Copilot for Pro, Pro+, Max, Business, and Enterprise — IDE, CLI, coding agent, and Mobile. Usage is billed at the provider list price.

On Business/Enterprise, new models usually auto-enable unless your org’s model policy says otherwise. Worth a quick glance at your settings if you manage Copilot for a team.

GitHub changelog →

Bedrock ships Sonnet 5.5 the same day

If you route production AI through AWS, Sonnet 5.5 is already on Bedrock (Global CRIS id global.anthropic.claude-sonnet-5-5). Same model family, familiar AWS controls — handy if Bedrock is your front door.

AWS ML blog →

Microsoft’s new Copilot: Home, Code & Autopilot

Microsoft rolled out a refreshed Copilot lineup: Home (chat + cowork + Office), Code (sandboxed apps powered by the same tech as GitHub Copilot, with Managed Runtime in preview), and Autopilot (a persistent proactive agent, private preview).

FinOps for AI also expands cost controls across Code and Managed Runtime — useful if you’re watching spend as agents get more ambitious.

Microsoft blog →

If you use GitHub Copilot…

As of 28 Sep, org/repo “Default” code-review effort now means Balanced (was Lite) — so reviews may spend more AI credits. Pin Lite explicitly if you want the cheaper default.
