OpenAI’s GPT-6 Cyber finds more bugs, and stays in bounds

OpenAI launched GPT-6 Cyber, a cybersecurity model trained to find and validate exploitable vulnerabilities while sticking to the scope researchers set. On ExploitGym it scored 48.5%, up from 32.1% for GPT-5.6 Cyber, and in alignment tests it avoided out-of-scope services in 99.93% of runs without its deployment prompt, and 100% with it.

OpenAI says researchers used it to develop 948 privilege-escalation exploits in Linux and find 81 previously unknown high-severity Firefox bugs, with Mozilla shipping fixes for many of them. Access starts with approved Daybreak Red customers via the API and Codex.

Google’s Gemini Omni 1.2 Flash is generally available

Gemini Omni 1.2 Flash is now generally available on the Gemini API and Google Cloud. Clips go up to 15 seconds (from 10), you can edit the same clip in a multi-turn chat instead of starting over, and 720p video is $0.07 per second — about 30% less than Omni 1.1 Flash.

Google says reference following is stronger for products and characters, drafts can start at 360p or 720p and upscale later, and outputs carry a SynthID watermark. It’s also rolling into Flow, Google Vids, Ads, and the Gemini app for AI Ultra subscribers.

From the inbox: why AI progress feels jagged

In Understanding AI, Timothy B. Lee borrows the robotics idea of the sim-to-real gap to explain why models can leap ahead in programming, maths and cybersecurity while everyday professions still look mostly the same. Tasks you can faithfully simulate improve fast and cheap; messy real-world work doesn’t.

Walking works in sim because the floor doesn’t fight back; hammering a nail often doesn’t, because tiny physics errors break the transfer. Lee’s point for white-collar work is that lots of valuable jobs are more like hammering than chess — hard to put in a clean training loop — so don’t expect 2027 to suddenly look like sci-fi just because benchmarks keep rising.

From the inbox: scaling Slack and GitHub with Maude Lemaire

The Pragmatic Engineer’s new episode with Maude Lemaire covers nearly eight years scaling Slack’s backend, database pain at GitHub’s Rails monolith, and a stretch improving time-to-first-token at Cursor. The war stories are great on their own — custom emoji capped at 23 to avoid thundering herds, a homemade load tester for half a million WebSockets — but the AI bit is the keepers.

For foundational platform work, Maude personally verifies everything she gets from an LLM before she builds on it. Judgment stays human; the model is a helper, not the decision-maker.

Hands-on pick: build an AI DevOps health agent on AWS

If you want a practical Bedrock project this weekend, NextWork’s Build an AI DevOps Health Agent on AWS has you deploy an AgentCore harness that writes boto3 in a code interpreter, reads your account with least-privilege IAM, and returns a severity-rated health report. CloudWatch traces show every decision and line of code.

It’s a clean fit if you’re already on Bedrock: read-only by default, optional secret mission to write a risk-scored JSON report to S3, then tear it all down with agentcore destroy so you don’t leave spend running.
